This folder contains the scripts used to run simulations. The scripts are in two folders:


01_quantify_benefits_remote_captures: code to assess the benefits of including biologging data using simulations. Specifically, the code allows to simulate data and analyze it with the model in 4 different species (roe deer, rock partridge, wandering albatross, polar bear) with varying recapture probabilities and probabilities of deploying a biologger at capture. 


02_model_validation_polar_bear: code to assess the performance of the model applied to polar bears when all biologically relevant covariates considered in the case study are included.
